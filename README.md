# AdmitHub – College Admission Management System

## Project Overview
AdmitHub is a Java Full Stack web application designed to manage college admission applications. Students can register, log in, submit applications, and track their application status. Administrators can review applications and approve or reject them.

## Technologies Used
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA and Hibernate
- Thymeleaf
- MySQL
- Maven
- IntelliJ IDEA

## Main Features
- Student registration and login
- Online admission application submission
- View submitted applications and application details
- Track application status
- Admin dashboard with application counts
- Approve or reject applications
- Role-based access control

## Database
Database name: `admission_db`

The database backup is provided separately as `admission_db.sql`, if included in the submission.

## How to Run
1. Install Java 21, Maven, and MySQL.
2. Configure the database connection in the project's application configuration.
3. Create the `admission_db` database and ensure the configured MySQL credentials are correct.
4. Open the project in IntelliJ IDEA and allow Maven dependencies to load.
5. Run the Spring Boot application.
6. Open `http://localhost:8080` in your browser.
